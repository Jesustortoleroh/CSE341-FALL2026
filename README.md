# CSE341 - Contacts API

CRUD API for contacts using Node.js, Express and MongoDB Atlas.

## How to run it

Run `npm install` and `npm start` from the project folder in the terminal.

Test the endpoints in the `contacts.rest` file with Rest Client or another similar tool.

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| GET | /contacts | Get all contacts |
| GET | /contacts/:id | Get one contact |
| POST | /contacts | Create a contact |
| PUT | /contacts/:id | Update a contact |
| DELETE | /contacts/:id | Delete a contact |
